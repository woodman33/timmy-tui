## Required implementation and expected output

Each tool probe has its own `try/catch`, timeout and output-schema check; orchestration uses `Promise.allSettled` without a shared catalog-construction exception that defeats isolation. A broken card identifies the environment variable **name** and violated rule, never its configured value. All unaffected cards remain present and byte-identical under fixed fixture state. A timeout or invalid output is a truthful per-tool unknown/setup-needed result, never a success or SDK availability claim.

A failed import followed by failed rollback throws `AggregateError([importErr, rollbackErr], msg, {cause: importErr})`. The error array retains original object order and identity; diagnostic rendering exposes both messages with import refusal first. Preserve a separately held pre-import snapshot even if rollback mutates the working copy or throws. Successful rollback keeps the original import refusal and restores the complete prior document. No removal of existing recovery behavior is accepted.
