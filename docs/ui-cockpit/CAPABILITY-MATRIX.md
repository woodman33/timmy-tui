Date: 2026-10-12. Source: the tree at `4b5cfc5` (2026-10-12). Generated by `node scripts/inventory/inventory.mjs --date 2026-10-12`, with
[`INVENTORY.md`](INVENTORY.md) (every dependency, for those who need it) and [`inventory/capabilities.json`](inventory/capabilities.json) (these rows,
machine-readable). One row per user-facing capability: which capabilities there are, their screen, renderer, inputs and outputs
and owner come from the hand-kept `inventory/overlay.json`; every control path is checked against the code, and every status
comes from the feature checklist, the ledger, the tests named, the recorded test runs, the Mac rehearsals and git.

**How to read it.** Each status is the highest that has its own evidence, with the revision of that evidence:

- **researched**: read from documentation or source; nothing of it is built here.
- **designed**: a written design says how Timmy does it; no code yet.
- **implemented**: its code is in this tree; no automated test was found for it.
- **tested here**: automated tests exercise it, named, with the recorded run that covers each file's current version (the full suite at `5e5cbb3`, or a helper's own run of a file added later); "fakes" names the stand-ins.
- **live-qualified on the Mac** ("live on the Mac" in the summary): it ran for real on the operator's Mac in a recorded, scripted rehearsal (r19 to r25), named with its revision and what ran. This is not a formal qualification (AGENTS.md section 5), and it says nothing of visual or usability acceptance.

**Backend** is the work itself; **UI** is the surface a person operates (a typed REPL command or CLI verb, a button on the live board, in Studio or the companion, the monitor). An agent tool and an MCP tool are paths for an agent, not a person's UI. **Visual acceptance** and **usability acceptance** belong to the operator alone: every row says "not reviewed" unless the operator recorded otherwise (none has been recorded). A **control path** is listed only when the code has it; a named path the code does not have is reported, and a capability without any path says so ("a documentation link or viewer alone is incomplete integration", the operator, 2026-10-11).
