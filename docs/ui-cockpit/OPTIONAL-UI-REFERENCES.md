# Optional Timmy UI references

The operator saved a set of UI concept sheets as references for development, without making them required.

They are advisory design references. Use the useful ideas, adapt or combine the options, and keep implementing the
full agreed feature scope. The operator's current instructions, [AGENTS.md](../../AGENTS.md), the design contracts in
this folder and the [feature checklist](FEATURE-CHECKLIST.md) govern: a feature missing from a sheet still belongs in
Timmy, and technical details stay available through advanced views.

## The reference pack

The sheets are kept privately on the operator's own computer, outside this repository, and are not distributed with
it. A developer without access continues from the governing plans; the pack is optional.

Eight sheets each compare two directions: the top row is "Focused Workspace" (option A), the bottom row "Command
Deck" (option B). Each row pairs two surfaces:

| Sheet | Paired surfaces |
|---|---|
| Studio | a blank template chooser; an editable canvas |
| Terminal | the inline REPL; a fullscreen watch and monitoring view |
| Browser | project and references; results and review |
| Workflows | the upmd document and its graph; run controls and recovery |
| Control Room | crew dispatch; tools and connections |
| VoxVision | 3D measurement; an image and dataset observatory |
| Creative | native 3D parameter authoring; motion and editorial |
| Memory | logs and recall; tested improvement |

"VoxVision" and "Memory" are working labels.

## How to read them

- The sheets are generated concepts with sample data, not screenshots of implemented features. Pictured tool
  availability, IDs, hashes, measurements and success states are illustrative: never reuse them as run evidence or
  show them as if real.
- A pictured panel or control does not prove that its integration exists or works. Implementation and qualification
  status come from source review and observed runs (the feature checklist and the ledger, `CHECKPOINTS.md`).
- The visual direction to keep: readable charcoal and off-white, Timmy Homebrew green for interaction and primary
  actions (never as proof), restrained secondary colours, room for artwork's own colours, a clear primary action and
  progressive disclosure.
- Keep durable job identity, progress, results and receipts, cancellation and recovery usable throughout; keep native
  editable artifacts beside previews and renders; keep private projects, stories, characters, assets and rejected work
  private.

Round R4 drew on the Workflows and Creative sheets for the board's flow cards (step strips, a summary over details,
an artifacts row, the After Effects timeline; ledger row 152).
