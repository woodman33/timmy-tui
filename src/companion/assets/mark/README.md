# The T mark (a proposed mark, not a final mascot)

The Rive source of the companion page's T mark, taken from the operator's design preview (R11 round 4; the one thing taken
from it): `scene.rml` (the artboard `TimmyMark`, 128 × 128: a black ground, an amber T, its `Idle` animation) and
`rive.yaml`. The page draws `timmy-mark.riv` here through `@rive-app/canvas` (served by the companion at `/vendor/rive/`);
the binary is not in this folder yet (the preview's transfer carried the source only), so the page draws its text mark
until it is built from this source and placed here as `timmy-mark.riv`.
